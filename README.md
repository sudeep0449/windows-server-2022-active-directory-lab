# Windows Server 2022 – Active Directory Infrastructure Lab

## Lab Overview

A hands-on lab covering the installation and configuration of Windows Server 2022 in a virtualized environment (Oracle VirtualBox), from a bare server through to a fully promoted Active Directory Domain Controller. Practical experience was gained in server deployment, Active Directory Domain Services (AD DS), Domain Controller configuration, Organizational Unit (OU) administration, user account management, password administration, and everyday Windows Server management tasks. This lab forms the base domain environment (`sudeep.local`, server `winserver2022`) used across the other Active Directory labs in this portfolio.

## Environment

- **Platform:** Windows Server 2022, running in Oracle VirtualBox
- **Server name:** `winserver2022`
- **Domain:** `sudeep.local`
- **Organizational Units:** `Finance`, `HR`, `Staff`
- **Sample domain users:** David Lee, Mike Brown, John Smith, Sarah Wilson

## Topics Covered

- Windows Server 2022 installation
- VirtualBox configuration
- Server initial configuration and computer renaming
- Static IP address configuration
- Remote Desktop configuration
- Time zone configuration
- Windows Updates
- Active Directory Domain Services (AD DS) installation
- Domain Controller promotion
- DSRM (Directory Services Restore Mode) password configuration
- Organizational Unit (OU) creation
- User account creation
- Password reset administration
- Account disable and enable
- Account unlocking

## Conclusion

Successfully deployed Windows Server 2022 and promoted it to an Active Directory Domain Controller, then carried out day-to-day identity administration on top of it — creating Organizational Units and user accounts, resetting passwords, and disabling, enabling, and unlocking accounts. These are foundational Windows Server and Active Directory administration skills directly applicable to IT Help Desk and Junior System Administrator roles.
